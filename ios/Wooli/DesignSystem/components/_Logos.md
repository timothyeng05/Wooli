# Logos

- `wooli-sheep.svg`: the Wooli sheep mark. Its outline, face and legs are `logo-outline` (#1d4ed8), the inner ears `logo-inner` (#2563eb), and the wool and eyes `logo-wool` (white). It's multi-ink, so it can't be recoloured. Place it on `card`, `background` or a `ticket`. This is an exact SVG of the `WooliLogo` drawing in `Theme.swift` (viewBox 100×108).
- `wooli-app-icon.png`: the 1024×1024 iOS app icon, with the sheep on a blue gradient. Use it wherever the app itself is represented (App Store, website header at 32px with 8px corners).

There is no wordmark file. The website sets "Wooli" in bold type next to the icon.
